VERSIÓN WEB MUNICIPAL — PUCYURA 2026

Contenido:
- index.html: portada + revista + menú + compartir
- hero.svg: cabecera gráfica en SVG
- assets/pages/: 71 páginas en JPG optimizadas para web

Cómo publicar:
1. Suba la carpeta completa WEB_MUNICIPAL_PUCYURA_2026 a su servidor web.
2. Mantenga la estructura de carpetas.
3. La página principal debe ser index.html.
4. Al publicarse, el botón Compartir usará automáticamente la URL pública actual.

Funciones:
- Portada a pantalla completa
- Botón ABRIR REVISTA
- Vista tipo revista / pasar páginas
- Contador de páginas
- Menú de secciones
- Pantalla completa
- Compartir por WhatsApp
- Compartir por Facebook
- Copiar enlace
- Adaptable a celular y computadora

Nota:
- hero.svg es editable y puede usarse como cabecera o banner en el sitio municipal.
